## What's new in 0.8.1

- **The connection list scrolls visibly.** On a small screen the list, the sidebar and the pinned list now get the same slim scrollbar as the other panes when they do not fit, so connections further down no longer hide without a sign.
- **Dragging a connection onto a group** no longer trips over the list's own drag signals: the list's signals have names of their own, and the drop no longer makes Qt warn.

## Security review

Reviewed everything since 0.8.0 against `docs/security-review.md`. The changes are interface only: no new data reaches a shell, a command line, a file or the keyring, and nothing new is read from servers, sync or import files. The new snapshot action that sizes the window is reachable only through the snapshot hook (`OMAREMOTE_SNAPSHOT`), which another account cannot set. Nothing found.
