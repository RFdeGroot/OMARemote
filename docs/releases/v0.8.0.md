## What's new in 0.8.0

- **Import from other clients.** *Import…* (Settings › Import & export) also opens Windows `.rdp` files, several at once, and Remmina profiles. Two buttons read Remmina's own folder and the hosts in `~/.ssh/config` (Included files too). A list shows what was found before anything is added. New connections are switched on. Connections you have already, ones listed twice, and ones that cannot be imported say so. Remmina's groups are kept; everything else goes into the group *Imported*.
- **Importing again adds nothing twice.** A connection that is here already (same protocol, host and port, or an ssh alias and the host name it stands for) is left exactly as it is. So the same file twice, or two files that overlap, never doubles a connection, and a file can never change a connection you have. Passwords stay behind. Nothing in an imported file turns off certificate checks or shares a folder, whatever the file asks for.
- **Session keys of your choice** (Settings › Keyboard). OMARemote's keys inside a session can be **Ctrl+Alt** (as before), **Right Ctrl** or **Ctrl+Alt+Shift**. Right Ctrl works like VirtualBox's host key: it never reaches the remote side, so layouts where Windows reads Ctrl+Alt as AltGr (Polish, German on Windows) and apps with Ctrl+Alt shortcuts keep them. Ctrl+Alt+Shift is for keyboards without a Right Ctrl, such as a MacBook's. The status bar and the keymap sheet show the keys you chose. The setting is per system.
- **Settings › Import & export**, a section of its own. *Export…* and *Import…* open the file chooser straight away, and a line under them says what happened last (where the last export went and when, what the last import added). The keymap sheet (`?`) runs them too: type *import* or *export* and press ⏎.
- **Settings fit their content.** The panel is as tall as its tallest section needs, at most the window, and keeps that height when you switch sections.
- **Panes that scroll show it.** Settings, the editors, the keymap sheet and the detail pane get a slim scrollbar when their content does not fit.

## Security review

Reviewed everything since 0.7.0 against `docs/security-review.md`. Three kinds of attacker were considered: a malicious server, a malicious sync or import file, and another account on the same machine.

- **Found and fixed (since 0.3.1):** a connection's name went into `~/.ssh/omaremote.conf` with its line breaks. Another system, or whoever can write the sync folder, could rename a connection you gave an SSH key to, so that the name added a `Host *` block with a `ProxyCommand`. With *Use in a terminal* on (Settings › SSH, off by default), that command would have run on your next ssh. Names now lose their control characters in that file, and a key path with a space, a quote or a `#` is left out of it. Covered by `tests/test_import.py`, which fails without the fix.
- **Found and fixed (new import):**
  - An imported connection in a group with a credential set took that set over. A crafted Remmina profile naming one of your groups could have sent the set's password to its own host. Imported connections now always ask for their credentials.
  - The import list did not show a connection's gateway. A downloaded `.rdp` with a harmless host and a hostile gateway is a known phishing trick; the list now shows *via gateway …*.
  - A FIFO or device named `.rdp` in a folder made the import hang. Only ordinary files are read.
  
  Each has a test that fails without the fix.
- **Import, otherwise:**
  - Hosts and gateways pass the same check as sync (`HOST_RE`: no leading `-`, nothing but a plain name), fields the same length limits.
  - Control characters are stripped from every value.
  - Files over 1 MiB are refused, and at most 500 files and 2000 connections are read per import.
  - OMARemote's own `~/.ssh/omaremote.conf` is never read back.
  - File names and the connections picked go to the import commands in the environment, not on the command line, where other accounts could read them (file names are often server names).
- **Session keys:** with Right Ctrl chosen, Right Ctrl is never sent to the remote side, and while it is held no key is. It counts only while Ctrl is down as well, so a missed release never leaves keys taken.
- **Left as it is:** an SSH key named in a Remmina profile comes along. It is a path on your own system, used only for the host you imported, and the list shows that host before anything is added.
