## What's new

SSH tabs now work like Ghostty, Omarchy's terminal, in almost everything you would notice day to day.

- **Scrolling and scrollback as in Ghostty**: the same wheel and trackpad speeds (your Ghostty
  `mouse-scroll-multiplier` counts), Ghostty's scrollback size, and a scrollbar that shows while you
  hover or scroll. The other scrollbars in OMARemote now show the same way.
- **Selecting**: double-click selects a word, triple-click a line. A selection goes to the primary
  selection and a middle click pastes it, as Ghostty's `copy-on-select` and `middle-click-action`.
- **Links**: hold ctrl over a URL (or a program's OSC 8 link) to see where it goes, ctrl+click to
  open it. Only the link types Ghostty recognises open (web, mail, ssh, git and the like), never a
  file on this computer.
- **Search**: `ctrl+shift+f` opens a find bar that searches the whole scrollback, jumps while you
  type, and marks matches in the Omarchy theme's accent; Enter and shift+Enter step through them.
- **Browse files opens where the shell is**, when the remote shell reports its directory (OSC 7).
- **The cursor blinks** as Ghostty's, in the style your Ghostty config sets.
- **The bell**: the tab and window title get a bell and the tab is marked until you look at it, as
  Ghostty's `bell-features` (a sound too, if you set one).
- **Desktop notifications** from programs in the terminal (OSC 9 and 777), click one to go to its tab.
- **Progress bar**: programs that report progress (OSC 9;4) show it along the top of the tab.
- **Light or dark**: programs that ask (Neovim, for one) hear whether your Omarchy theme is light or
  dark, and are told again when you switch themes.
- **Focus reporting** for programs that ask (vim's FocusGained, tmux `focus-events`).
- **The font follows Omarchy**: a new font picked with Omarchy's font menu shows in open tabs at once.
- **Ligatures**: `->`, `!=`, `===` and friends are drawn joined, as Ghostty draws them, never under
  the cursor. Not when your default terminal is Alacritty or foot, which have none; Ghostty's
  `font-feature` lines count (`font-feature = -calt` turns them off).

## Security review

The changes since 0.10.1 were reviewed against docs/security-review.md, by us and by the Reviewer
session (code review and the omarchy-plugin-security skill). What a remote server can now send was
checked in particular:

- Notification text goes to the desktop over D-Bus, never on a command line; it is capped in size,
  rate-limited (at most one a second, the same text not again within 5 s), and can never read as
  markup (see below).
- The shell's directory opens in the file manager only as a folder inside that connection's own
  mount, checked after resolving links.
- The primary selection is read only right after your own middle click in that tab, and not while
  Clipboard is off or passwords are held back.
- Links open only after a ctrl+click, and only for Ghostty's link types (web, mail, ssh, git and the
  like); never a file on this computer, and never a link with spaces or control characters. As in
  Ghostty, the link you open reaches your browser on its command line.
- Every line from a session (titles, directories, links, notifications, search) is capped, and the
  new caches (search marks, shaped text) are bounded.

Found and fixed before release:

- **A notification could carry a working link** (Reviewer). Notification text was escaped for
  servers that read markup, but Omarchy's own notifications decode that escaping before they let
  bold text and links through: a remote program could show a clickable link, with a label of its
  choosing, in a notification from OMARemote. Now `&`, `<` and `>` never leave at all (look-alikes
  take their place), in the title too, and right-to-left overrides and other invisible controls are
  left out. The test runs the text through Omarchy's own notification renderer.
- **Browse files put the folder's path on a command line** (our own review). It opened the mounted
  folder with `xdg-open <path>`, which any account on the computer can read in `/proc`; with Browse
  where the shell is, that path would hold the remote folders. The folder now goes to your file
  manager over D-Bus (Omarchy's Folio and Flea, Nautilus and Dolphin take it that way); otherwise
  xdg-open gets a link named after the connection's id. The folder opened is the one that was
  checked to be inside the connection's mount, after resolving links (Reviewer).
- Smaller: the cap of 64 on Ghostty's `font-feature` lines held per line only (Reviewer).
