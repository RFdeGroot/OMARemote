## What's new

- **Fixed: the cursor in SSH tabs follows the arrow keys again** (broken since 0.9.18). Left and right moved the cursor,
  but the block stayed drawn where it was, so after pasting a command you could not see where you
  were editing. The block now moves with every key, along the line as well as up and down.
- Six tests that could fail on a busy machine now wait for what they check instead of a fixed time.

## Security review

The changes since 0.10.0 were reviewed against docs/security-review.md. The only change outside the
tests is in omaremote-ssh's drawing: the cursor's column and style, as the terminal library reports
them, now also decide whether its row is redrawn. They are only compared with what was drawn last;
no new input, file, command or limit is involved. Nothing was found.
