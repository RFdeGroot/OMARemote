## What's new

- **A new terminal in SSH tabs.** SSH tabs now run on Ghostty's terminal emulation (libghostty-vt)
  instead of libvterm: Nerd Font icons and emoji sized as Ghostty sizes them, grapheme clusters (flags,
  skin tones) as one character, the Kitty keyboard protocol, and no flicker when you select text.
- **Zoom in SSH tabs.** Ctrl+= and Ctrl+- make the text bigger or smaller in that tab; Ctrl+0 resets it.
- **A tab closes when its session ends.** Typing `exit` or signing off now closes the tab by
  default. A failure, an end within a few seconds of connecting, or an open files question still shows
  the panel with the reason and Reconnect. To keep the panel, go to Settings › Sessions and pick
  "Show Reconnect".
- **SSH reconnects after a reboot.** A `sudo reboot` over SSH used to end the session; now the tab
  waits and connects again when the computer is back.
- **Trackpad scrolling at the right speed** in Gliff and VNC tabs: a smooth scroll in Gliff, and small
  steps that add up to whole notches in VNC instead of being lost.
- Fixed: the editor's protocol buttons showed the wrong protocol after switching connections, and the
  list sometimes started with another row selected than its first.

### For packagers

Building now needs `curl` and `xz`. `libvterm` is no longer used. The build downloads libghostty-vt
1.0.1 and Zig 0.17.1 (pinned by sha256) and links libghostty-vt statically, so nothing new is needed at
runtime.

## Security review

The changes since 0.9.17 were reviewed against docs/security-review.md. Checked in particular:

- **The new terminal's build inputs.** libghostty-vt 1.0.1 and Zig 0.17.1 are downloaded over HTTPS
  only (redirects too), with a size cap and a deadline, and nothing is unpacked or run before its
  sha256 matches the one kept in the repository (native/ghostty-vt/build.sh and the PKGBUILD, kept equal
  by a test). The pinned hashes were checked again independently: Zig's against ziglang.org's
  index.json, libghostty-vt's tarballs against their minisign signatures from Ghostty's release key.
  Zig builds offline (`--system`, all its packages come from the checked deps tarball).
- **What a server can make the terminal do.** Kitty graphics are off (no images stored), escape
  sequences of that kind are buffered up to 64 KiB, titles are cut at 4 KiB and shown as plain text,
  and the title report (CSI 21 t) stays off, as in Ghostty, so a server cannot have a title it set typed back
  at the prompt. OSC 52 only writes the clipboard (never reads it), plain text only, up to 1 MiB, and
  only with the connection's Clipboard switch on. Pasted text goes through Ghostty's paste encoder,
  which takes out whatever could end a bracketed paste early.
- **Bounds.** The icon cache is cleared at 4096 entries, the terminal is at most 4096×4096 cells, zoom
  stays between 4 and 48 points, and the Nerd Font table lookup is range-checked (its generator refuses a
  table of the wrong shape).
- **Found and fixed:** a remote program that stopped reading its input (a server flooding terminal
  queries and never reading the answers) could hang the SSH session process for good. It then took no
  Stop either, because the answers were written in a loop with no deadline. The loop now ends on a stop
  and drops what the server leaves unread for 5 seconds. A slow server that still reads keeps everything.
  This was already the case with libvterm, but Ghostty answers more queries. Two tests in
  tests/test_ssh.py fail without the fix.
- The supervisor's new `connectedAt` and `stopped` fields are numbers and a boolean it writes itself.
  Closing a tab when a session ends never happens after a failure, a stop from the UI, or an end within
  5 seconds of connecting.
- Trackpad scrolling: the new numbers on the `wheel` line come from the view, not from a server, and a
  missing one reads as 0.

Left as it is: Gliff's queue of messages to a server that stops reading has no limit of its own. It only
grows from our own pings and input, and the session's 4 GiB memory ceiling ends it cleanly.
