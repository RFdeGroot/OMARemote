## What's new

- **Glassy and Transparent windows.** OMARemote follows Omarchy 4.5's Window Opacity setting
  (Appearance › Windows), live, without a restart:
  - **Glassy**: the connections window's panes (header, sidebar, list, details, editors, the pinned
    list, the status bar) become frosted glass over Hyprland's blur. Text is lifted just enough to
    stay readable (4.5:1, the accent 3:1) on every Omarchy theme.
  - **Transparent**: the panes at Omarchy's own 0.985 while focused and 0.96 when not.
  - **Opaque**, and Omarchy before 4.5: everything solid, as before.
- **SSH terminals as see-through as Omarchy's.** An SSH tab's background takes your default
  terminal's opacity from the current theme (0.65 in Glassy, or the theme's own), so it matches
  Ghostty, foot, Alacritty or kitty next to it. Text and cells with a colour of their own stay solid.
- **Remote desktops always stay solid**: RDP, VNC and Gliff tabs, the area around them, cards and
  menus. OMARemote adds no Hyprland rule of its own; while an SSH tab is shown, the window keeps its
  `terminal` tag (for Omarchy's clipboard keys), so Omarchy fades it slightly, as it fades foot.
- Fixed: `omaremote restart` started by a relative path (`bin/omaremote restart` in a checkout)
  closed the window without starting it again.
- Fixed: with `XDG_STATE_HOME` set, SSH tabs looked for the theme's terminal colours in the wrong
  place; Omarchy always writes the current theme under `~/.local/state`.

## Security review

The changes since 0.9.18 were reviewed against docs/security-review.md. Checked in particular:

- **What OMARemote now reads from other programs.** Omarchy's toggle files are only tested for being
  there (`test -f` in a process of its own, the paths as arguments, never code), so a FIFO, a device
  or a huge file in their place costs nothing. The default terminal's theme file goes through
  `read_text` (no blocking open, ordinary files only, 1 MiB at most) and only a number between 0 and
  1 is taken from it. `xdg-terminal-exec` and `hyprctl` answers are capped in size and time
  (`xdg-terminal-exec`'s answer was read uncapped before; it is now 4 KiB in 2 s), and the blur
  brightness is range-checked. The window reads the new `terminal-glass` answer capped at 4 KiB,
  checks its types and ranges, and keeps Omarchy's values on anything odd.
- **What a server can do to the terminal's transparency.** Nothing: only omaremote-ssh paints the
  alpha, from the view's own `opacity` line (clamped to 0-255). A colour a server sets (OSC 11) keeps
  it, and Kitty images stay off. RDP, VNC and Gliff frames are never read with an alpha channel.
- **The view's new frame format.** A frame mapped before the tab knew it was a terminal is read again
  in the other format over the same mapping, kept alive by the old image; the scene graph node is
  made anew so it blends. Tests check the alpha in the shared frame and through the view, for a tab
  told before and after its first frame.
- **Readability on glass.** Text is checked on every installed Omarchy theme over the blur's
  brightest and darkest backdrop, on selected and hovered rows, and through Hyprland's own fade of
  the window while an SSH tab is shown, rounded to 8 bits as the screen does.
- No new process carries a connection's name, host or user on its command line; nothing new is
  written to disk.

Nothing was left open.
